
# Calculator - The Odin Project

- This project is an exercise I am completing for one of the Javascript lessons in the Odin Project Full Stack Foundations Course 

- I began this project while in the middle of the Array methods exercises (ADHD, LOL) and still have to complete the DOM manipulation and Objects lessons in order to truly understand and be able to comoplete this assignment. I will probably complete another project in a different repo before finishing this one, but I am excited to document my progress. 

1. I began this project by writing out a basic algorithm using psuedocode. 

The Psuedocode Algorithm was typed in my iPhone Notes:

- Creatve a div to represent the outer shell of a Casio calculator 

- Create 28 divs inside the outer div to represent the buttons of a Casio 

- Develop the UI to be simple with divs separated evenly 

- Create a 'total' variable and use DOM manipulation to attach is to the second div

- Use DOM manipulation to add functionality to each button including numbers and operators 

This was one of my first attempts at writing Pseudocode and I see the need to imorove my directions and understanding of the assignment. 

2. Writing the code of the project began by structuring the calculator using HTML:

- I decided to use flexbox since I haven't learned grid as of yet. The Casio calculator is structured in blocks so it was pretty easy to develop. 

- I decided to group the HTML elements into classes. One class is for numbers and the other is for operators. It took me about 30 minutes to rememner that I can use classes. 

3. The next step was styling the calcualtor with CSS. WHat good is an HTML structure without its counterpart CSS file to dress it up?

- Coding the CSS was a journey. I inititally coded each HTML element one by one until realzizing I could group the elements/buttons into classes. I then did a bulk edit to the elements: numbers and operators. This was a strong lesson in classes, CSS selectors and properties. 

4. The next step is Javascript - variables for buttons

- I began the JS script by declaring each button with its own variable. I have not done the OBjects lesson yet, but have read a few docs on them and can kinda recognize how they would be useful in grouping the buttons/elements. I may be wrong on this assumption but will see.
